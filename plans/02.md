# 02 — Shareable Link

## Approach

Use **URL query parameters** to encode calculator state. This is inherently stateless (no server, no storage), domain-agnostic (`window.location` is dynamic), and works perfectly with static GitHub Pages hosting.

## Implementation (all changes in `src/app.js`, `src/index.html`, and `src/style.css`)

### 1. URL serialization / deserialization (`app.js`)

**`serializeState(state)`** — serialize non-null state values to URL query params. Always encodes `brix` (source of truth), plus `dose`, `water`, `method`, `temperature`, and optionally `brewWeight`. Anchor defaults to `brix` on restore. Uses `URLSearchParams`.

**`deserializeState()`** — parse `window.location.search` on page load, return a partial state object with parsed values. Validates numeric ranges, ignores invalid params.

### 2. Restore state on load (`app.js`)

Call `deserializeState()` at startup, merge into the default state object, then call `render()`. Existing empty-state behavior is preserved when no params are present.

### 3. "Copy Link" button (`index.html` + `app.js` + `style.css`)

Add a button next to the Reset button in the header. On click:
- Build the full URL: `window.location.origin + window.location.pathname + '?' + serializeState(state)`
- Copy to clipboard via `navigator.clipboard.writeText()`
- Briefly show "Copied!" feedback (flashing text, ~1.5s), then revert to button label

### 4. Domain accommodation

All URLs are built from `window.location.origin + window.location.pathname` — zero hardcoding. Works on `localhost`, `wirasuta.github.io`, or any custom domain.

## URL format example

```
https://wirasuta.github.io/brix-coffee-tds/?brix=9.0&dose=18&water=288&method=filter&temperature=20
```
